# CombatGameplay
A C++ Melee combat gameplay system on unreal 5.4.4

## Controls
| Key     | Controls         |
|---------|------------------|
| Tab     | Toggle Tutorial  |
| Esc     | Toggle Menu      |
| L Alt   | Toggle Movement  |
| W A S D | Movement         |
| LMB     | Attack           |
| L Shift | Dodge            |

## Implemented:
-  Motion matching locomotion system (Idle, Walk, Jog)
-  Directional dodge
-  Camera bobbler for immersive traversal experience
-  Sword-based combat with a combo
-  Motion warping based targeting system
-  Hit detection by the collision
-  Hit stop & Camera shake for immersive attack experience
-  4-directional hit reaction
-  Patrol enemy with sight sense & damage sense
-  Sword-based enemy with a combo
-  Widgets (with widget animation)
