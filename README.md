# CombatGameplay
**A C++ Melee combat gameplay system on unreal 5.4.4**

_The system features a **motion-matching** locomotion setup that seamlessly blends between idle, walk, and jog states,
along with a **directional dodge** for dynamic movement. To enhance traversal, a **camera bobbler** is implemented for added immersion. 
Combat is **sword-based**, supporting **combo attacks** powered by a **motion-warping targeting system**, with precise hit detection through collision,
hit stop, and camera shake to amplify impact. The player can also trigger **four-directional hit reactions** for more realistic feedback.
Enemies include **patrolling AI** that use **sight and damage sensing, with sword-based combat combos** of their own. 
The overall experience is supported by **polished UI elements**, including animated widgets for smooth visual feedback._
